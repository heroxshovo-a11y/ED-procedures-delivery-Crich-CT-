# ED Pocket v2.0 — PRIVATE TRAINING PREVIEW

This code is a **clinical training preview**. No independent physician, neonatal instructor, obstetric specialist, or pharmacist has signed off on this release. It is **not approved for bedside clinical decision-making**.

Includes seven emergency rapid cards, 24-topic reference, five bundled anatomy plates, emergency stepper, neonatal timer/HR-breathing rehearsal, PPH measurement thresholds, training-only facility equipment planning, local-only scenario review scheduling, offline self-test, and per-topic review status.

The detailed handbook has only had an AI-assisted risk triage. Verify all doses, equipment, technique and contraindications with specialists and local policy before use. Source package and tests: ED_Pocket_v2.0_Private_Preview.zip supplied in ChatGPT.

To run: serve this folder via HTTPS or local HTTP server; service workers do not function from file://. In addition to automated tests, an actual iPhone airplane-mode test is required.

No patient identifiers, doses changed, or generated anatomy were added in v2.0.
